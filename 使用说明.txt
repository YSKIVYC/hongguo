红果短剧助手 - 使用说明
========================

【怎么用】
1. 双击「红果短剧助手.exe」，会自动弹出黑窗口 + 浏览器打开页面
   （黑窗口是程序本体，看剧期间别关；关掉窗口 = 退出程序）
2. 从微信/QQ 复制短剧分享链接，粘贴到输入框，点「解析剧集」
3. 出现剧集列表后：
   - 点每集右边的蓝色 ▶ 按钮 → 直接在线播放（免广告，可拖进度条，自动连播）
   - 勾选集数点「开始下载」→ 批量下载 720P 完整正片

【下载到哪】
默认保存在 exe 旁边的「短剧下载」文件夹，按剧名分文件夹。

【常见问题】
- 浏览器没自动打开 → 手动访问 http://127.0.0.1:18090
- 双击没反应/被杀毒拦截 → 在杀毒软件里允许运行（PyInstaller 打包的正常现象）
- 解析失败 → 链接可能过期，重新从 App 分享一次
- Windows SmartScreen 提示 → 点「更多信息」→「仍要运行」

仅支持 Windows 系统，无需安装 Python 或其他任何软件。
